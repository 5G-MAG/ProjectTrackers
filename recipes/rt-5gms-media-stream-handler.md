## rt-5gms-media-stream-handler
**What it implements:** The 5GMS Client "Media Stream Handler" (Media Player) for 5GMSd, ETSI TS 126.501 framework. It plays back a media presentation and exposes play, pause, seek and stop to the 5GMSd-Aware Application; it consumes media from the 5GMSd AS at M4d [Readme.md]. It is an Android library wrapping ExoPlayer, exposing TS 26.512 M7d functionality, with a `MediaSessionHandlerAdapter` that opens a Messenger connection to the Media Session Handler [Readme.md]. The code also builds consumption reports and QoE metrics reports (3GPP DASH metric scheme `urn:3GPP:ns:PSS:DASH:QM10`) [app/src/test/.../QoEMetricsReportingControllerTest.kt]. The test checks the report against a "Rel-19 XSD" [app/src/test/.../ReproduceQoeReportComplianceTest.kt].
**Language and build system:** Kotlin Android library (`com.android.library`), Gradle Groovy DSL, wrapper Gradle 9.5.0 [app/build.gradle, gradle/wrapper/gradle-wrapper.properties]. AGP 9.2.0, Kotlin plugin 2.3.21 [build.gradle]. Java 17, `jvmToolchain(17)`, compileSdk 37, minSdk 29, targetSdk 34, version 1.3.0 [app/build.gradle]. Media3 (ExoPlayer, DASH, HLS, UI) 1.10.0 [app/build.gradle]. CI uses JDK 17, distribution oracle [.github/workflows/unit-test-gradle.yml].
**Build:**
- Dependency first: the build needs `com.fivegmag:a5gmscommonlibrary:1.3.0` [app/build.gradle], resolved from `mavenLocal()` first [settings.gradle]. The CI checks out rt-5gms-common-android-library (branch `development`) and runs `./gradlew publishToMavenLocal` there before building [.github/workflows/unit-test-gradle.yml]. The Readme does not mention this step.
- Build the `aar`: `./gradlew assemble`; output in `app/build/outputs/aar/` [Readme.md].
- Publish for consumers (for example rt-5gms-application): `./gradlew publishToMavenLocal`; consumers use `implementation 'com.fivegmag:a5gmsmediastreamhandler:1.0.0'` as the Readme example (artifact version in the build file is 1.3.0) [Readme.md, app/build.gradle].
- CI runs the Gradle task `build` [.github/workflows/unit-test-gradle.yml]. On push to `main` another workflow runs `publish` to GitHub Packages (needs `GITHUB_TOKEN`) [.github/workflows/deploy-package.yml].

**Run it locally:** It is a library, not a standalone process; no start command, port or config file found. It binds to the Media Session Handler by component name `com.fivegmag.a5gmsmediasessionhandler` / `...service.MediaSessionHandlerMessengerService` [app/src/main/java/.../service/MessengerService.kt]. The manifest declares a `<queries>` entry for that package, location and phone permissions, and cleartext traffic [app/src/main/AndroidManifest.xml]. It needs the Media Session Handler APK on the same device and a host app.
