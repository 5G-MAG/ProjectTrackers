## rt-5gms-application
**What it implements:** Test and demo applications for other 5G-MAG 5GMS reference tools [README.md]. Two folders: `fivegmag_5GMSdAwareApplication` (Android reference 5GMSd-Aware Application; it controls the Media Session Handler at M6d via IPC and the Media Player at M7, and reads content lists from an application-specific M8 catalogue that 3GPP does not standardise) and `fivegmag_ExoDvbi_player` (ExoPlayer plus DVB-I Reference Client in a WebView) [README.md, fivegmag_5GMSdAwareApplication/Readme.md, fivegmag_ExoDvbi_player/README.md]. This recipe covers the first folder unless noted.
**Language and build system:** Kotlin Android app, Gradle Groovy DSL, wrapper Gradle 9.5.0, AGP 9.2.0, Kotlin plugin 2.3.21 [fivegmag_5GMSdAwareApplication/build.gradle, gradle/wrapper/gradle-wrapper.properties]. Java 17, `jvmToolchain(17)`, compileSdk 37, minSdk 29, targetSdk 34, versionName 1.3.0, Media3 1.10.0, Retrofit 2.9.0 [app/build.gradle]. CI: JDK 17, distribution temurin [.github/workflows/unit-test-gradle.yml].
**Build:**
- Dependencies first, in this order, each with `./gradlew publishToMavenLocal` run in its own checkout: rt-5gms-common-android-library, then rt-5gms-media-stream-handler (CI uses branch `development` of both) [.github/workflows/unit-test-gradle.yml; fivegmag_5GMSdAwareApplication/Readme.md "Install dependencies"]. The app needs `a5gmscommonlibrary:1.3.0` and `a5gmsmediastreamhandler:1.3.0` [app/build.gradle]; `mavenLocal()` is listed in `settings.gradle`.
- App: `cd fivegmag_5GMSdAwareApplication/` then `./gradlew assemble`; APKs in `fivegmag_5GMSdAwareApplication/app/build/outputs/apk` (`debug`, `release`) [fivegmag_5GMSdAwareApplication/Readme.md]. Other commands: `./gradlew assembleDebug`, `./gradlew clean assembleDebug`, `./gradlew installDebug`, `./gradlew compileDebugKotlin` [fivegmag_5GMSdAwareApplication/AGENTS.md]. CI runs `build --stacktrace` with build root `fivegmag_5GMSdAwareApplication` [.github/workflows/unit-test-gradle.yml].
- ExoDvbi player (not built by CI): `git clone --recurse-submodules git@github.com:5G-MAG/rt-5gms-application.git`, apply `patch/Exoplayer.patch` inside the ExoPlayer submodule with `git apply Exoplayer.patch`, then `./gradlew assembleRelease` [fivegmag_ExoDvbi_player/README.md]. Submodule: https://github.com/google/ExoPlayer.git, branch `dev-v2` [.gitmodules].
**Run the unit tests:** JUnit 4.13.2, run from `fivegmag_5GMSdAwareApplication/` [app/build.gradle, fivegmag_5GMSdAwareApplication/AGENTS.md]. All: `./gradlew test` or `./gradlew testDebugUnitTest`. One class: `./gradlew testDebugUnitTest --tests "com.fivegmag.a5gmsdawareapplication.ExampleUnitTest"`. One method: `./gradlew testDebugUnitTest --tests "com.fivegmag.a5gmsdawareapplication.ExampleUnitTest.addition_isCorrect"` [AGENTS.md]. Tests: `app/src/test/java/com/fivegmag/a5gmsdawareapplication/ExampleUnitTest.kt` (placeholder) and `MetadataProviderTest.kt` (4 tests of `resolvePosterUrl`). Instrumented (needs device): `./gradlew connectedDebugAndroidTest`, one class with `-Pandroid.testInstrumentationRunnerArguments.class=com.fivegmag.a5gmsdawareapplication.ExampleInstrumentedTest` [AGENTS.md]; file `app/src/androidTest/.../ExampleInstrumentedTest.kt`. The ExoDvbi folder has no tests found.
**Run it locally:** Install with `adb devices` and `adb -s <deviceID> install -r app/build/outputs/apk/debug/app-debug.apk`; start from the app screen or `adb shell am start -n com.fivegmag.a5gmsdawareapplication/com.fivegmag.a5gmsdawareapplication.MainActivity ` [fivegmag_5GMSdAwareApplication/Readme.md]. Config: `app/src/main/assets/app_config.json` lists sources with `name`, `m8Url`, `metadataUrl`: "5G-MAG online reference" (`https://rt.5g-mag.com/m8.json`) and "Docker" (`http://<YOUR_IP_HERE>:8000/m8.json`, metadata on port 3344) [app/src/main/assets/app_config.json]. Needs the Media Session Handler APK on the device [fivegmag_5GMSdAwareApplication/Readme.md] and, for the Docker source, an M8/metadata server and a 5GMSd AF/AS.
**Exercise a feature end to end:** The example M8 file `app/src/main/assets/examples/m8.json` sets `m5BaseUrl` to `http://192.168.178.56:7778/3gpp-m5/v2/` and three services (VoD "Big Buck Bunny", VoD "Tears of Steel", Live "LiveSim2") with M4d locators `http://192.168.178.56/m4d/provisioning-session-<id>/...` [that file]. The app passes the M5 URL and a ServiceListEntry to the Media Stream Handler [app/src/main/java/.../DetailActivity.kt]. No docker compose, script or CI step for this is in the repository; CI only builds [.github/workflows/unit-test-gradle.yml].
**Fixtures, mocks and sample data:** `app/src/main/assets/app_config.json`, `examples/m8.json`, `examples/metadata.json` (titles, descriptions, poster URLs, `mediaType`) [paths under fivegmag_5GMSdAwareApplication/].
**Logs and how to see that it worked:** Android `Log` tags `5GMS Aware Application`, `ConfigProvider`, `MetadataProvider` [MainActivity.kt, ConfigProvider.kt, MetadataProvider.kt]. At start it logs "5GMS Common Library Version: ..." and "5GMS Media Stream Handler Version: ..." [MainActivity.kt]. Error lines: "Failed to fetch M8 data", "Failed to parse M8 data", "Failed to load local config". A success marker for playback: not found in the repository.
**Conventions for contributors:** `fivegmag_5GMSdAwareApplication/AGENTS.md` exists: license header on every source file, `I` prefix for interfaces, EventBus `@Subscribe(threadMode = ThreadMode.MAIN)`, no ktlint/detekt/spotless, `./gradlew lint`, branch from `development`. Gitflow in the Readme. Issue template `.github/ISSUE_TEMPLATE/feature_request.md`. PRs to `main`/`development` trigger CI. No CLAUDE.md or CONTRIBUTING.md.
