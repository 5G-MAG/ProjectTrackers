## rt-5gms-common-android-library
**What it implements:** Not a 3GPP network function. An Android library with models and helper classes shared by the 5GMSd-Aware Application, the 5GMSd Media Stream Handler and the 5GMSd Media Session Handler [Readme.md]. Contents seen in the source: IPC message type constants for the session handler (`SessionHandlerMessageTypes`, 14 types) [app/src/main/java/com/fivegmag/a5gmscommonlibrary/helpers/Constants.kt]; models `ServiceAccessInformation`, `ServiceListEntry`, `M8Model` [app/src/main/java/.../models/]; consumption reporting and QoE metrics reporting classes [app/src/main/java/.../consumptionReporting/, .../qoeMetricsReporting/]; `PlaybackRequest` [app/src/main/java/.../session/PlaybackRequest.kt]. Which TS clause each model follows: not found in the repository.
**Language and build system:** Kotlin Android library (`com.android.library`, `kotlin-parcelize`, `maven-publish`), Gradle Groovy DSL, wrapper Gradle 9.5.0 [app/build.gradle, gradle/wrapper/gradle-wrapper.properties]. AGP 9.2.0, Kotlin plugin 2.3.21 [build.gradle]. Java 17, `jvmToolchain(17)`, compileSdk 37, minSdk 29, targetSdk 34 [app/build.gradle]. Published as `com.fivegmag:a5gmscommonlibrary:1.3.0` [app/build.gradle]. Uses Jackson 2.21.x (databind, XML, Kotlin module), Retrofit 2.9.0, media3-exoplayer 1.10.0 [app/build.gradle]. CI uses JDK 17, distribution oracle [.github/workflows/unit-test-gradle.yml].
**Build:** No sibling dependency (no `mavenLocal()` in `settings.gradle`).
- `./gradlew assemble`; `aar` output in `app/build/outputs/aar/` [Readme.md].
- Publish locally for the other 5GMS client projects: `./gradlew publishToMavenLocal` [Readme.md]. This is the step the CI of rt-5gms-media-session-handler, rt-5gms-media-stream-handler and rt-5gms-application runs on this repo's `development` branch [.github/workflows/unit-test-gradle.yml in each of those repositories].
- Consumers add `mavenLocal()` and `implementation 'com.fivegmag:a5gmscommonlibrary:1.0.0'` (Readme example; the version in the build file is 1.3.0) [Readme.md, app/build.gradle].
- CI runs the Gradle task `build` on pull requests to `main` and `development` [.github/workflows/unit-test-gradle.yml]. On push to `main`, `publish` goes to GitHub Packages with `GITHUB_TOKEN` [.github/workflows/deploy-package.yml].
**Run the unit tests:** JUnit 4.13.2 [app/build.gradle]. Plain JVM tests in `app/src/test/java/com/fivegmag/a5gmscommonlibrary/`: `UtilsUnitTest.kt` (9 tests, URL port and host-info parsing) and `M8ModelUnitTest.kt` (1 test, builds an `M8Model` and checks fields). Instrumented: `app/src/androidTest/java/com/fivegmag/a5gmscommonlibrary/ExampleInstrumentedTest.kt`. Command to run unit tests: not found in the repository (the CI runs `build`) [.github/workflows/unit-test-gradle.yml]. Command for ONE test: not found in the repository.
**Run it locally:** Nothing to run; it is a library with no service, port or config file [app/src/main/AndroidManifest.xml has only an `<application>` element].
**Exercise a feature end to end:** Not found in the repository. It is exercised only through the other 5GMS client repositories that include it [Readme.md].
**Fixtures, mocks and sample data:** None as files. The tests build objects inline (for example `ServiceListEntry("id1", "name1", ...)`) and use sample MPD URLs as strings (`https://dash.akamaized.net/akamai/bbb_30fps/bbb_30fps.mpd`) [app/src/test/.../M8ModelUnitTest.kt, UtilsUnitTest.kt].
**Logs and how to see that it worked:** No logging calls found under `app/src/main`. Success for a build is the CI `build` task passing [.github/workflows/unit-test-gradle.yml]; for a publish, the artifact appears in the local Maven repository (path: not found in the repository).
**Conventions for contributors:** Gitflow; `development` is the integration branch and feature work starts from it [Readme.md]. `kotlin.code.style=official` [gradle.properties]. No AGENTS.md, CLAUDE.md, CONTRIBUTING.md or issue templates.
