## rt-5gms-application-provider
(Source: shallow clone of 5G-MAG/rt-5gms-application-provider at 297c7be6965c, 2026-08-03. Nothing was built or run. Paths in brackets are repo-relative.)
**What it implements:** The 5GMS Application Provider side of a 3GPP 5G Media Streaming architecture: tools that talk to the 5GMS Application Function over reference point M1 (Python CLI, FastAPI Management UI, Postman and Insomnia collections) [README.md]. Provisioning operations are those of TS 26.512; the UI also publishes the M8 JSON [management-ui/README.md]. Status badge: "Under Development" [README.md].
**Language and build system:** Python, setuptools, requires-python ">=3.7"; deps httpx[http2]>=0.21.1, h11>=0.11.0, h2>=4.1.0, aiofiles>=0.7.0, pyOpenSSL>=20.0.1; installs scripts `msaf-configuration`, `m1-session`, `m1-client` [python/pyproject.toml]. UI: FastAPI>=0.109.1, uvicorn>=0.23.2, pytest, pytest-asyncio [management-ui/requirements.txt]; frontend is vanilla JS, no JS build step found [management-ui/README.md, management-ui/src].
**Build:** CLI: `cd rt-5gms-application-provider` then `python3 -m pip install ./python`; venv variant: `python3 -m venv venv` then `venv/bin/python3 -m pip install ./python` [python/README.md]. UI deps: `cd management-ui/` then `pip3 install -r requirements.txt` [management-ui/README.md]. Docker: `sudo docker-compose build` [management-ui/README.md]; the Dockerfile (FROM ubuntu:latest) apt-installs build deps, runs `git clone -b development --recurse-submodules https://github.com/5G-MAG/rt-5gms-application-function.git`, `meson setup --prefix=`pwd`/install build`, `ninja -C build`, `meson install -C build --no-rebuild`, then `pip3 install -r management-ui/requirements.txt` and `pip3 install ./python` [Dockerfile]. Sphinx docs: python/docs/Makefile wraps sphinx-build; no instructions given [python/docs/Makefile].
**Run the unit tests:** No unit tests. Only `management-ui/tests/integration_test.py` (pytest + pytest-asyncio + httpx, one test `test_provisioning_session_lifecycle`). README command: `cd ~/rt-5gms-application-provider/management-ui/tests` then `pytest integration_test.py` [management-ui/README.md]. Needs a running UI and AF; base URL from env `FASTAPI_URL`, default `http://localhost:8000` (.env loaded via python-dotenv) [management-ui/tests/integration_test.py]. Running one test: not documented; there is only one function. CI does not run it [.github/workflows/].
**Run it locally:** Docker: `sudo docker-compose up`, then open `localhost:8000` [management-ui/README.md]. Compose service `app-ui`, container `rt-5gms-application-provider`, port 8000:8000, mounts `.:/ui` [docker-compose.yml]. `start.sh` starts `/rt-5gms-application-function/install/bin/open5gs-msafd -c local-msaf.yaml &` and then `uvicorn server:app --reload --host 0.0.0.0 --port 8000` in /ui/management-ui [start.sh]. local-msaf.yaml: sbi 127.0.0.22, M1 127.0.0.23, M5 127.0.0.24, MAF 127.0.0.25 (all port 7777), no_tls true, open5gsIntegration yes [local-msaf.yaml]. Without Docker: install the AF (link in README), run `~/rt-5gms-application-function/install/bin/open5gs-msafd`, then `cd management-ui/` and `uvicorn server:app --reload` (port 8000); behind a proxy use `http_proxy= https_proxy= uvicorn server:app --reload` [management-ui/README.md]. M1 default 127.0.0.23:7777, config `~/.rt-5gms/m1-client.conf` (root: /etc/rt-5gms/m1-client.conf) [python/lib/rt_m1_client/configuration.py]. Env: `OPTIONS_ENDPOINT`, `CORS_ORIGINS` [management-ui/server.py]; `CMCD_INFLUXDB_URL` (default http://localhost:8086), `CMCD_INFLUXDB_DB` (default analytics) [management-ui/README.md].
**Exercise a feature end to end:** The repo has no mock AF and no compose-based test; the peer is a real AF (Docker above). CLI usage is delegated to the AF README "Testing" section [python/README.md]; Postman usage to a Getting-Started page [postman/README.md]. CLI syntax (from the module docstring, which spells the program `m1-session-cli`; the installed script is `m1-session`): `m1-session new-provisioning-session [-e <application-id>] [-a <asp-id>]`, `m1-session new-stream ... <ingest-URL> [<entry-point-suffix-URL>]`, `m1-session set-stream -p <provisioning-session-id> <ContentHostingConfiguration-JSON>`, `m1-session list [-v]` [python/src/rt_m1_apps/m1_session.py]. `m1-client provisioning create <address:port> (-d|-u) <external-app-id> [<asp-id>]`, `m1-client hosting create <address:port> <provisioning-session-id> <CHC-JSON-file>` [python/src/rt_m1_apps/m1_client.py]. `msaf-configuration` applies /etc/rt-5gms/initial-config.json to a running AF [python/src/rt_m1_apps/msaf_configuration.py]. Full AF+AS+AP stack: see rt-5gms-examples recipe1.
