## rt-5gms-media-session-handler
**What it implements:** The 5GMS Client "Media Session Handler" (5GMSd) of the 5G Media Services framework in ETSI TS 126.501. It fetches Service Access Information from the 5GMSd AF at M5d and exposes M6 to the 5GMSd-Aware Application and the Media Player [Readme.md]. Built as an Android Messenger Service that talks over IPC to the Media Stream Handler and the 5GMSd-Aware Application [Readme.md]. Status badge: "Under Development" [Readme.md].
**Language and build system:** Kotlin Android app, Gradle (Groovy DSL) with the wrapper at Gradle 9.5.0 [gradle/wrapper/gradle-wrapper.properties]. Android Gradle Plugin 9.2.0, Kotlin plugin 2.3.21 [build.gradle]. Java 17 source/target and `jvmToolchain(17)`; compileSdk 37, minSdk 29, targetSdk 34, versionName 1.3.0 [app/build.gradle]. CI uses JDK 17, distribution oracle [.github/workflows/unit-test-gradle.yml]. Android SDK setup: not found in the repository.
**Build:**
- Dependency first: publish the Common Android Library to the local Maven repository [Readme.md]. The CI does this in a checkout of rt-5gms-common-android-library (branch `development`) with `./gradlew publishToMavenLocal` [.github/workflows/unit-test-gradle.yml]. The app needs `com.fivegmag:a5gmscommonlibrary:1.3.0` [app/build.gradle]; `mavenLocal()` is the first repository [settings.gradle].
- Then in this repo: `./gradlew assemble` [Readme.md]. APKs land in `app/build/outputs/apk` (`debug` and `release` folders) [Readme.md]. CI runs the Gradle task `build` [.github/workflows/unit-test-gradle.yml].

Unit tests: `app/src/test/java/com/fivegmag/a5gmsmediasessionhandler/ExampleUnitTest.kt`, a placeholder (`assertEquals(4, 2 + 2)`) [app/src/test/.../ExampleUnitTest.kt]. Command to run unit tests: not found in the repository (the CI runs `build`) [.github/workflows/unit-test-gradle.yml]. Command to run ONE test: not found in the repository.
**Run it locally:**
- Install: `adb devices`, then `adb -s <deviceID> install -r app/build/outputs/apk/debug/app-debug.apk` [Readme.md].
- Start: from the Android app screen, or `adb shell am start -n com.fivegmag.a5gmsmediasessionhandler/com.fivegmag.a5gmsmediasessionhandler.MainActivity ` [Readme.md].
- The Messenger service is exported with the intent action `com.fivegmag.a5gmsmediasessionhandler.Service` [app/src/main/AndroidManifest.xml]. Cleartext HTTP is allowed (`usesCleartextTraffic="true"`) [app/src/main/AndroidManifest.xml].
- Config file: `app/src/main/assets/config.properties.xml`, one key, `defaultServiceAccessInformationTimerInterval` = 10 [app/src/main/assets/config.properties.xml]. No listening port; it is a client. The M5 base URL is given at runtime by the client app in the message bundle key `m5BaseUrl` [app/src/main/java/.../controller/ServiceAccessInformationController.kt].
- Other services needed: a 5GMSd AF reachable at M5 and a client app that sends the messages. Which AF build and address to use: not found in the repository.
**Exercise a feature end to end:** Not documented in this repository (no docker compose, scripts or sample payloads). What the code calls on M5: `GET service-access-information/{provisioningSessionId}` with `If-None-Match` and `If-Modified-Since` headers [app/src/main/java/.../network/IServiceAccessInformationApi.kt]; `POST consumption-reporting/{provisioningSessionId}` as JSON [network/IConsumptionReportingApi.kt]; `POST metrics-reporting/{provisioningSessionId}/{metricsReportingConfigurationId}` as XML [network/IMetricsReportingApi.kt]. The Readme only names the Media Stream Handler and the 5GMSd-Aware Application as IPC peers [Readme.md].
