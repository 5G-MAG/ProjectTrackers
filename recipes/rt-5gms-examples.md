## rt-5gms-examples
(Source: shallow clone of 5G-MAG/rt-5gms-examples at 4cee6085b733, 2026-08-03, VERSION 1.3.0 [VERSION]. Nothing was built or run. Paths in brackets are repo-relative.)
**What it implements:** Not a 3GPP function. Example projects around 5GMS [Readme.md]: (a) a Docker Compose setup running 5GMS Application Function, Application Server and Application Provider, matching TS 26.501 A.3 (downlink, AF and AS in an external Data Network), exposing M1, M4, M5 and M8 [5gms-docker-setup/Readme.md]; (b) `express-mock-af`, a static-response mock serving M8 and M5 Service Access Information [express-mock-af/Readme.md]; (c) example JSON configs based on TS 26.512 Rel-17.4.0 [examples-files/Readme.md].
**Language and build system:** Docker Compose files (`name: recipe1`) plus Dockerfiles (AF and AP on ubuntu:24.04, AS on ubuntu:22.04, simple-express-server on node:20-alpine) [5gms-docker-setup/recipe1/docker/*/Dockerfile]; express-mock-af is Node.js with npm, express ~4.16.1, script `start` = `node ./bin/www` [express-mock-af/package.json]. Minimum Docker, Compose or Node versions: not found in the repository.
**Build:** Mock: `cd express-mock-af` then `npm install` [express-mock-af/Readme.md]. Docker: compose builds on `up`. Each Dockerfile clones the upstream repo at its default branch: AF `git clone --recurse-submodules` then `meson build && ninja -C build` and `meson install --no-rebuild -C build`; AS `python3 -m pip install .`; AP `pip install -r management-ui/requirements.txt` and `./python`; simple-express-server clones rt-common-shared then `npm ci --omit=dev` [recipe1/docker/*/Dockerfile]. Nothing is pinned except the CMCD toolkit ref `a3b8ab7ebd8b492bb8a944b71b011e5d49224318` (override with `CMCD_TOOLKIT_REF`) [recipe1/compose/docker-compose-cmcd.yml]. Builds need network access.
**Run the unit tests:** None. No test folder, no test script in package.json, no .github folder (no CI) [express-mock-af/package.json]. One test per component: not applicable.
**Run it locally:** Docker, standalone: `cd ~/rt-5gms-examples/5gms-docker-setup/recipe1` then `docker compose --env-file .env -f compose/docker-compose_5gms_without_5GC.yml up` [5gms-docker-setup/recipe1/Readme.md]. First set the host IP: README says replace `<<ADD_YOUR_IP_HERE>>` in configs/media.conf (`m5_authority = <ip>:7778`) and in configs/initial-config.json (`"domainNameAlias"`) [Readme.md]; the files actually contain `<YOUR_MACHINE_IP_HERE>` [configs/media.conf, configs/initial-config.json]. Services and ports: application-server 80 (M4); application-function 5555 (M1), 7778 (M5), 4444, 6464 (MAF); application-provider 8000 (Management UI); simple-express-server 3344 (metadata and posters) [compose/docker-compose_5gms_without_5GC.yml]. With 5G Core (Open5GS): `docker network create 5g-mag`, `docker volume create open5gs_db_data`, `docker volume create open5gs_db_config`, `docker compose --env-file .env -f compose/docker-compose-5gc.yml up -d`, then `docker compose --env-file .env -f compose/docker-compose-5gms.yml up` [Readme.md]; images ghcr.io/5g-mag/{nrf,ausf,udm,udr,nssf,bsf,pcf,amf,smf,upf,webui}:${OPEN5GS_VERSION}, mongo:${MONGODB_VERSION}, versions in .env (OPEN5GS_VERSION=v2.7.7, MONGODB_VERSION=6.0) [compose/docker-compose-5gc.yml, .env]. Mock: `cd express-mock-af` then `npm start`, port 3003 (env `PORT` overrides) [express-mock-af/Readme.md, express-mock-af/bin/www].
**Exercise a feature end to end:** (1) Docker: on start the AP entrypoint runs `m1-session configure set m1_port $M1_PORT`, `m1-session configure set m1_address application-function`, then `msaf-configuration` (reads configs/initial-config.json: three streams, BBC, Axinom, 5G-MAG LiveSim, each with consumption and metrics reporting) and then `uvicorn server:app --reload --host 0.0.0.0 --port 8000` [docker/application-provider/entrypoint.sh, configs/initial-config.json]. Compose sets `RUN_MSAF_CONFIGURATION_TOOL=true`, `RUN_MANAGEMENT_UI=true`, `M1_PORT=5555` [compose/*.yml]. Then: `curl -X POST http://localhost:5555/3gpp-m1/v2/provisioning-sessions -H "Content-Type: application/json" -d '{"aspId": "aspId", "appId": "appId", "provisioningSessionType": "DOWNLINK"}'` creates a session via M1 [Readme.md]; Management UI at `http://127.0.0.1:8000/`; its QoE Metrics tab takes the container path `/af-reports` [Readme.md]. Sample M8 (`examples/m8.json`) shows entry points like `http://<ip>/m4d/provisioning-session-<id>/bbb/2/client_manifest-common_init.mpd`; the app config points at `http://<ip>:8000/m8.json` and `http://<ip>:3344/metadata_local.json` [recipe1/examples/m8.json, simple-express-public/app_config.json]. Playback needs a 5GMS Aware Application, which is not in this repo [Readme.md]. CMCD: `docker compose --env-file .env -f compose/docker-compose_5gms_without_5GC.yml -f compose/docker-compose-cmcd.yml up -d`; collector :3000, Grafana :8081 (admin / grafana) [recipe1/Readme.md]. (2) Mock AF, no AF needed: `GET http://localhost:3003/m8/m8.json`; `GET http://localhost:3003/3gpp-m5/v2/service-access-information/<id>` (ids 1 to 6 defined; 3 and 4 return only id and type); `POST /3gpp-m5/v2/consumption-reporting/<psId>` (JSON body, 204, writes `public/reports/<psId>/consumption_reports/<reportingClientId>_<timestamp>.json`); `POST /3gpp-m5/v2/metrics-reporting/<psId>/<metricsConfigId>` (Content-Type application/xml body, 204, writes `public/reports/<psId>/metrics_reports/<metricsConfigId>/<timestamp>.xml`) [express-mock-af/app.js, routes/*.js]. README documents only the first two GETs; no client command for the POSTs is given.
